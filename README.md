# ☕ Cafe Billing & Online Order System (Java Swing)

## 📌 Description
This is a Java-based GUI application with login and billing system.  
It supports online ordering (delivery/takeaway), payment methods, and bill generation.

## 🚀 Features
- Login system (authentication)
- Item selection with quantity
- Discount using coupon codes
- GST calculation (5%)
- Delivery & takeaway options
- Customer name and address
- Payment methods (Cash, UPI, Card)

## 🛠️ Technologies Used
- Java
- Swing (GUI)

## ▶️ How to Run
1. Open project in any Java IDE
2. Run LoginFrame.java
3. Login using:
